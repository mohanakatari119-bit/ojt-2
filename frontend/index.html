API Monitor
v1.0 — self-hosted

Capture, inspect,
debug your APIs.

Drop-in request logging with structured storage, real-time metrics, replay, and alert rules. No third-party service required.

  • Structured request and response logging with full header and body capture
  • Replay any captured request against any target URL with custom overrides
  • Alert rules that fire on status code, latency, or error conditions
  • Aggregate metrics — error rate, latency percentiles, top paths
  • API key auth with per-service isolation
Ingest endpoint: POST /v1/logs — authenticated via Bearer token.
